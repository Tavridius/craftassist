# 🛠️ StalZone Craft Helper — План MVP

Помощник крафта для игры **STALZONE**. Тапнул предмет → видишь, из чего крафтится,
сколько стоят ингредиенты на аукционе, и **выгодно ли крафтить** (скрафтить vs купить готовое).

---

## 🎯 Зафиксированные решения

| Вопрос | Решение |
|---|---|
| Доступ к API | **Демо-токен** (fake-цены `10000`). Реальные цены — сменой одной env-переменной на prod app-token позже. |
| Стек | **Отдельный FastAPI + Docker** на том же Ubuntu-сервере (`pavel@88.87.70.167`). |
| Регион | **RU** |
| Кэш | In-memory TTL на MVP; Redis — лёгкий апгрейд потом. |
| БД | Не нужна для MVP: рецепты/предметы — файлы из гит-репо, цены — живой аук. |

## 📦 Два источника данных

### 1. Рецепты + предметы — GitHub `EXBO-Studio/stalzone-database` (открыто, без токена)
Автообновляется при патчах игры. Скачиваем раз в сутки, парсим, строим индексы.

- `ru/listing.json` — индекс ~2288 предметов: `data`, `icon`, `name.lines.ru`, `color` (редкость), `status` (торгуемый / `NON_DROP` / `PERSONAL`).
- `ru/hideout_recipes.json` — **368 рецептов верстака**. Поле `recipes[]`, каждый:
  ```json
  {
    "result":      [{ "item": "okp24", "amount": 1 }],
    "ingredients": [{ "item": "z22k", "amount": 20 }, ...],
    "energy": 1000.0,
    "requirements": { "perks": {...}, "features": [...] },
    "category": {...}, "subcategory": {...}, "bench": "workbench"
  }
  ```
- `ru/barter_recipes.json` — бартер у торговцев: `item` (результат), `offers[].requiredItems[]`, `cost` (деньги).
- `ru/icons/**` — PNG-иконки по id.

> **Ключевой индекс:** обратный — `item_id → рецепт(ы), которые его дают`. Рецепты ссылаются на предметы короткими id (`zyv9`, `okp24`).

### 2. Цены аукциона — STALZONE API (нужен токен)
```
GET https://dapi.stalcraft.net/RU/auction/{item}/lots     → активные лоты (купить сейчас)
GET https://dapi.stalcraft.net/RU/auction/{item}/history   → недавние продажи (цена продажи)
Header: Authorization: Bearer <token>
```
Лот: `{ itemId, amount, startPrice, buyoutPrice, startTime, endTime, additional{} }`.

- Демо: база `dapi.stalcraft.net`, публичный токен из доков, **цены фейковые**.
- Prod: база `eapi.stalcraft.net`, одобренный app-token (API в бете, доступ по заявке на exbo.net).
- **Переключение demo↔prod = смена `API_BASE` + `API_TOKEN` в `.env`.**

## 🔌 Эндпоинты бэка (MVP)

| Метод | Путь | Отдаёт |
|---|---|---|
| `GET` | `/api/search?q=` | поиск по имени → `[{id, name, icon, color}]` |
| `GET` | `/api/item/{id}` | инфа о предмете + его рецепт(ы) |

## 💰 Логика «выгодно ли крафтить» — ДЕРЕВО крафта (реализовано)

Почти каждый ингредиент сам крафтится, и у многих рецептов несколько вариантов —
поэтому это рекурсивное дерево, а не один уровень:

```
obtain(item) = min( купить на ауке ,  по каждому варианту рецепта: craft(R) )
craft(R)     = ( Σ obtain(ingredient) × amount  +  деньги ) / result_amount
```

- **Глубина:** рекурсия на каждый ингредиент (`CRAFT_MAX_DEPTH`).
- **Варианты:** оцениваются ВСЕ (дедуп одинаковых бартеров), берётся дешёвый; остальные —
  как альтернативы (`CRAFT_MAX_VARIANTS`).
- **Обрезка:** где дешевле купить — ветка стоп (`src=аук`); дешевле крафтить — раскрывается.
- **Защита:** `path`-множество рвёт циклы, `memo` считает общие поддеревья один раз.
- **Вердикт:** `craft_cost(item)` (лучший по вариантам) vs `buyout(item)` → разница в %.

**Крайние случаи:**
- Ингредиент без лотов → «цена неизвестна»/«только крафт».
- Предмет без рецепта → «не крафтится».
- Демо-цены одинаковые (~10000) → вердикты искажены; норма до prod-токена.

**Перф на демо:** демо-API держит ~2 запроса/с. Глубокое дерево = много вызовов → холодный
запрос до ~60с (кэш 600с → далее мгновенно; nginx-таймаут /mvp = 120с). С prod-токеном
лимиты выше. Возможное улучшение: ленивое раскрытие узлов по клику.

## 📱 Фронт (mobile-first, 360–430px)

Грид предметов с иконками → тап → карточка:
- дерево ингредиентов с ценами и количествами,
- итоговая стоимость крафта vs цена готового,
- плашка **«ВЫГОДНО +23%» / «НЕВЫГОДНО −15%»**.

Ванильный JS достаточно для MVP. Кнопки вертикально, tap-target ≥44px.

## 🚀 Этапы

1. **Скелет + данные.** FastAPI, загрузчик БД из репо, индексы. `/api/search`, `/api/item`.
2. **Аукцион.** Клиент API + TTL-кэш, `/api/price`. Проверка на демо-токене.
3. **Крафт + выгода.** Склейка рецепта с ценами, рекурсия, `/api/craft` с вердиктом.
4. **Фронт.** Грид → карточка предмета с деревом и плашкой выгоды. Иконки.
5. **Деплой.** Dockerfile + docker-compose + nginx, поднять на Ubuntu-сервере.

## ⚠️ Риски / зависимости

1. **Реальные цены = prod-приложение STALZONE API** (по заявке, API в бете). До него — только демо (fake-цены). Это единственный внешний блокер для полноценной фичи выгоды.
2. **Rate-limit** prod-API → обязательно кэшировать цены (TTL), не долбить на каждый клик.
3. **Формат репо-БД может меняться** при патчах игры → парсер писать терпимым к отсутствующим полям.
