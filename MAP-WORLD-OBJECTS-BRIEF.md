# ТЗ: объекты мира из клиента на карту (травы, бартер, лут)

Задача для отдельной сессии. Составлено 31.10.2026. Контекст: метрика карты в
разговоре 31.10 и [AUDIT-UX-MAP-2026-10-28.md](AUDIT-UX-MAP-2026-10-28.md), раздел 3.

## Зачем

1. **Карта не связана с ядром сайта.** За 28–31.10 на /map перешли со /builds 2
   раза, с /craft 1 раз, с /market 0 раз. Основной трафик сайта — крафт, бартер,
   сборки и аукцион, а карта живёт отдельно.
2. **Своих данных на карте нет.** Все 2306 опубликованных объектов — импорт
   stalzone.wiki (`[wiki-import …]` в описании). У lunar-zone.ru на одном
   Севере 35 925 меток, у нас 1 171.
3. **Те, кто дошёл до карты, её используют:** глубина 8.2, 5 минут, отказы 10%.
   Если на карте будет то, что нужно для крафта, и к ней будут вести ссылки
   с крафта, её начнут использовать.

Цель: достать из клиента игры координаты объектов мира (сначала **травы**
и **бартерные предметы**) и показать их на карте. Затем связать карту с
/craft, /barter и карточками предметов кнопкой «где собрать».

## Где копать

Клиент: `D:\EXBO\runtime\stalcraft\`.

- `modassets/assets/` (45 ГБ): `gameobjects`, `vegetation`, `anomalies`,
  `containers.l`, `stalkermobs`, `pda`, `metadata`, `misc`. Описания пропов,
  скорее всего, лежат здесь. **Расстановка** может лежать здесь или отдельно.
- `map_cache/7.0/<мир>/reg.X.Y.mdat` — кэш регионов по 512 блоков. Сейчас там
  13 папок, и почти все — инстансы (`arena_raven`, `base_covenant`,
  `battlefield_kolizei_open`, `hideout`, `north_forge`, `north_inflow`,
  `prestige_map_1`, `signals_dungeon_*`…). **Папок основных миров (юг, север)
  нет.** Возможно, кэш пишется только для посещённых миров. Проверить: зайти
  в игре на Север, посмотреть, появится ли папка. В `scripts/wiki_map/wiki_solve.py`
  использовался `map_cache\5.0` с боксами локаций — там видно, как этот формат
  уже читали.
- `cache/` (17 МБ).
- Конвертер форматов клиента: `python -m scfile` (через него собираются тайлы,
  см. `scripts/gen_detail_pyramid.py`). Перед запуском нужен `NO_PROXY=*`:
  системный SOCKS-прокси ломает исходящие запросы.

**Первый шаг — разведка, без кода для сайта:**
1. Поиск строк `prop_herb`, `hellroot`, `gnosis`, `prop_barter`, `prikop` по
   `modassets` и `map_cache` (бинарно, `rg -a` или `grep -rla`), с учётом того,
   что часть файлов сжата.
2. Найти файл или набор файлов, где имя пропа стоит рядом с координатами.
   Проверить на известной точке: встать в игре у куста, снять координаты
   (F3 или `/coords`, если есть) и найти их в данных.
3. **Если расстановки в клиенте нет** (мир стримится с сервера), остановиться
   и написать владельцу, что нашёл. Не лезть в сетевой трафик и не трогать
   античит, без согласования не делать ничего, кроме чтения файлов на диске.

## Координаты

Детальный слой карты: **1 px = 1 блок мира**, начало пирамиды — регион
(-86, -38), регион 512 блоков (`_DETAIL_X0/_DETAIL_Y0` в
`backend/app/routers/api.py`, `XMIN/YMIN` в `gen_detail_pyramid.py`).

    px = X + 86 * 512
    py = Z + 38 * 512

Знак и ось Z проверить на 2–3 известных точках (например, по меткам вики,
которые уже совпали после регистрации изображений, или по зданиям на подложке).
У Лунара та же система: `originX: -11264` = -22·512 для Севера.

## Как класть на сайт

1. **Категории.** Добавить в `MAP_CATEGORIES` (`backend/app/routers/api.py`)
   `herb` (травы и грибы) и `barter` (бартерные предметы). Позже — `mineral`,
   `signal`, `med`, `crate`, `bag`, `safe`. `loot` уже есть. Значки по
   [MAP-ICONS-BRIEF.md](MAP-ICONS-BRIEF.md). До появления значков — emoji, как
   у остальных.
2. **Имя метки** — конкретный объект («Чертоцвет», «Гнозис»), а не категория:
   так работает фильтр и поиск.
3. **Тег источника** в описании: `[client-import <мир> <дата>]`, по аналогии с
   `[wiki-import …]`. Во всплывашке тег скрывается так же
   (коммит `90a5cc8`). Для `scripts/map_import.py` добавить флаг
   `--replace-client` по образцу `--replace-wiki`, чтобы после патча
   перезаливать выгрузку целиком.
4. **Импорт черновиками** через `scripts/map_import.py` (JSON-вход), проверка
   в /dev/map, публикация руками. Не публиковать сразу.
5. **Производительность.** Тысячи трав на одном виде Leaflet не потянет
   маркерами. Варианты: кластеризация (`Leaflet.markercluster`), canvas-рендер
   (`preferCanvas` / `L.circleMarker`) или показ категории только с зума N.
   По умолчанию массовые слои выключены, включаются фильтром.
6. **Скрипт выгрузки** положить в `scripts/` (например, `scripts/client_map/`),
   с докстрингом: откуда берёт, как запускать после патча. Сырые выгрузки в
   репозиторий не коммитить, если они большие.

## Связка с крафтом (ради чего всё)

1. Сопоставить травы и бартерку с предметами базы (`stalzone-database/ru/items`,
   например травы лежат в `items/misc/` — `npp9.json`, `prrd.json`). Нужна
   таблица «имя пропа → id предмета». Положить рядом со скриптом выгрузки.
2. На карте — ссылка `/map/<территория>?show=<item_id>`: открыть территорию
   с включённым слоем и подсветкой только этого объекта. Сейчас query-параметров
   у карты нет, их нужно добавить в `openMap` (`frontend/app.js`, ~строка 6860).
3. На карточке предмета, в /craft у ингредиента и в /barter — кнопка «Где
   собрать ▸ карта», если для предмета есть точки.

## Метрика

На карте сейчас нет ни одной цели. Добавить через `ymGoal` (`frontend/app.js`):
- `map_zone_open` — переход в территорию, параметр `zone`;
- `map_filter` — включение слоя, параметр `cat`;
- `map_marker_click` — клик по метке, параметр `cat`;
- `map_from_item` — переход по кнопке «где собрать», параметр `from`
  (`item`, `craft`, `barter`).

Цели завести в счётчике 110585101 (тип «JavaScript-событие»), иначе отчёта
не будет. Если токена на управление целями нет — передать владельцу список
идентификаторов.

## Этапы и точки остановки

1. **Разведка формата.** Итог: где лежит расстановка, как читается, проверка
   на 2–3 точках из игры. **Стоп, отчёт владельцу.**
2. Выгрузка трав и бартерки по Северу и Югу → JSON для `map_import.py`,
   оверлей на подложке для проверки (`scripts/wiki_map/render_pair.py`,
   `wiki_overlay.py` можно взять за основу).
3. Категории, производительность слоя, импорт черновиками на локальной базе,
   скриншоты.
4. Таблица «проп → предмет», кнопка «где собрать», query-параметр карты.
5. Цели Метрики.
6. Деплой — только по команде владельца (см. `DEPLOY.md`).

## Не делать

- Не брать и не расшифровывать данные Лунара или вики.
- Не трогать сетевой трафик игры, античит, память процесса — только файлы на
  диске.
- Не публиковать импорт без проверки в /dev/map.
- Не коммитить и не деплоить без просьбы владельца.
